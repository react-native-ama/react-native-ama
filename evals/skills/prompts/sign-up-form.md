Create a sign-up screen in `src/screens/SignUpScreen.tsx` and render it from `App.tsx` as the only screen of the app.

The form has three fields: full name, email address and password. All three are required, and the email must contain an "@". When the user submits an invalid form, show an error message under each invalid field. Add a "Create account" button at the bottom.

Use the libraries already installed in the project where they help. Don't install new dependencies.
