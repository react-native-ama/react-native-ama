Create a screen in `src/screens/FiltersScreen.tsx` and render it from `App.tsx` as the only screen of the app.

The screen has a title and a "Filters" button. Tapping the button opens a bottom sheet with three on/off filters: "In stock only", "Free delivery" and "On sale". Each filter is a row with its label and a switch. The sheet has an "Apply" button that closes it, and the user can also close it by tapping outside it.

Use the libraries already installed in the project where they help. Don't install new dependencies.
