# TextInput

TextInput is an extension of the [React Native TextInput](https://reactnative.dev/docs/textinput) component, [focused on accessibility](#accessibility-improvements).

```tsx
import { TextInput } from '@react-native-ama/forms';

<TextInput
  style={styles.input}
  accessibilityLabel="First name"
  onChangeText={newText => setText(newText)}
  defaultValue={text}
  hasValidation={false}
  renderLabel={a11yProps => (
    <Text {...a11yProps} style={styles.label}>
      First name:
    </Text>
  )}
/>;
```

## Accessibility improvements

Compared to the default React Native component, this custom component:

- Requires an `accessibilityLabel` (or `aria-label`) that matches the visible label
- Hides the label and the error from the screen reader through the `a11yProps` passed to `renderLabel` and `renderError` (they would provide redundant information)
- Handles the value `returnKeyType`
- Handles focusing the next form field when `returnKeyType` is **next**
- Checks for keyboard trap <DevOnly />

### accessibilityLabel

The input field must have an `accessibilityLabel` (or `aria-label`), and its visible label must be hidden from the screen reader to avoid the same label being announced twice.

AMA checks that a visible text on screen matches the `accessibilityLabel` (case-insensitive, ignoring one trailing symbol such as `:`), and reports [INPUT_HAS_NO_VISIBLE_LABEL](/docs/ama/checks) otherwise.

### returnKeyType

When the user lands on a `<TextInput />` the [`returnKeyType`](https://reactnative.dev/docs/textinput#returnkeytype) needs to be handled allowing them to either focus the next control, when `returnKeyType="next"`, or submit the form, when `returnKeyType="done"`. The React Native default `<TextInput />` allows customing the `returnKeyType` prop but leaves the developer to handle the action when the button is pressed.

Instead, the AMA customised `TextInput` automatically handles the property `returnKeyType` and its action:

- If the `TextInput` is the last one of the [Form](./Form.md) then sets `returnKeyType="done"`, otherwise `returnKeyType="next"`
- The next key focuses the next `TextInput` or [FormField](./FormField.md)
- The done button submits the [Form](./Form.md)

:::note

AMA does not alter the "returnKeyType" when manually passed as a prop.
:::

### Keyboard trap

Once the user presses the **next** key, AMA checks that the:

- The current `TextInput` does no longer have the focus
- If the next field is a `TextInput`, then check if it gained the focus

## Additional Props

### <Required /> `accessibilityLabel` / `aria-label`

The accessible name of the input. One of the two is required (not both). It must match the text of the visible label rendered by [`renderLabel`](#renderlabel).

| Type   | Default   |
|--------|-----------|
| string | undefined |

### `renderLabel`

Renders the visible label. It receives the `a11yProps` to spread on the label element, so that it's hidden from the screen reader:

- `importantForAccessibility: 'no-hide-descendants'`
- `accessibilityElementsHidden: true`

| Type                                    | Default   |
|-----------------------------------------|-----------|
| `(a11yProps) => React.ReactNode`        | undefined |

```jsx
<TextInput
  accessibilityLabel="Email address"
  hasValidation={false}
  renderLabel={a11yProps => <Text {...a11yProps}>Email address:</Text>}
/>
```

:::warning

Don't mark a required field only with an asterisk: AMA reports `INPUT_HAS_NO_VISIBLE_LABEL_ENDING_WITH_ASTERISK`. Say it in words instead, for example "Email address (required)".
:::

### `labelPosition`

Specify where to render the label.

| Type            | Default      |
|-----------------|--------------|
| 'beforeInput' \| 'afterInput' | 'beforeInput' |

### `nextFormField` _(optional)_


This parameter specifies the next form field to focus on when the next button is pressed.

| Type      | Default   |
|-----------|-----------|
| RefObject | undefined |

#### Example

```jsx
<TextInput
  style={styles.input}
  accessibilityLabel="Last name"
  onChangeText={newText => setText(newText)}
  defaultValue={text}
  hasValidation={false}
  renderLabel={a11yProps => <Text {...a11yProps}>Last name:</Text>}
  returnKeyType="next"
  nextFormField={emailRef}
  ref={lastNameRef}
/>
```

### `id`

The field ID. This info is stored, with the field `ref`, inside the [`<Form />`](./Form.md) component.

| Type   | Default   |
|--------|-----------|
| string | undefined |

### `nextFieldId`

The ID of the next field to focus when the user taps on the `next` button of the keyboard

| Type   | Default   |
|--------|-----------|
| string | undefined |

### <Required /> `hasValidation`

This property is used to know if the input can display an error, in case of failed validation; and if so is used to:

1. Set the [errorMessage](#errormessage), in case of failure, as part of the accessibilityHint
2. Hide the element rendered by [renderError](#rendererror) from the accessibility tree to prevent redundant information for the user


Here can be find more information about [error handling in Forms](/guidelines/forms#errors)

| Type    | Default   |
|---------|-----------|
| boolean | undefined |

### `hasError`

If true, the [errorMessage](#errormessage) is added to the `accessibilityHint` and [renderError](#rendererror) is rendered. The [`<Form />`](./Form.md) also uses it to focus the first invalid field when the submission fails.

| Type    | Default   |
|---------|-----------|
| boolean | undefined |

### `errorMessage`

The error announced by the screen reader, as part of the `accessibilityHint`, while `hasError` is true.

| Type   | Default   |
|--------|-----------|
| string | undefined |

### `renderError`

Renders the visible error when `hasError` is true. The position can be changed using the [errorPosition](#errorposition) property. It receives the same `a11yProps` as [renderLabel](#renderlabel), to spread on the error element so that it's hidden from the accessibility tree (the error is announced through the hint instead).

| Type                                    | Default   |
|-----------------------------------------|-----------|
| `(a11yProps) => React.ReactNode`        | undefined |

### `errorPosition`

The position where to render the [renderError](#rendererror) element

| Type            | Default      |
|-----------------|--------------|
| 'belowLabel' \| 'afterInput' | 'afterInput' |
